# Soft Actor-Critic for Dexterous Humanoid Hand Grasping on Complex Climbing Holds

Research project, MSc Computer Science (Robotics), IT University of Copenhagen.

I trained a simulated humanoid hand to grasp climbing holds using reinforcement
learning (Soft Actor-Critic) in MuJoCo, building on Google DeepMind's
[RoboPianist](https://github.com/google-research/robopianist).



📄 [Read the full report (PDF)](Soft_Actor-Critic_for_Dexterous_Humanoid_Hand.pdf)
